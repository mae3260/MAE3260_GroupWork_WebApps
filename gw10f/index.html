Problem 2: Implementing proportional control only

In this problem, we will consider proportional (P) control only, for a reference step input.

  • Run the MATLAB code (the editor below) to open Simulink.
  • Double-click the ‘PI Controller’ (control) block to open the PI Controller window.
  • Under the ‘Controller:’ drop down menu, select ‘PI’ for Proportional and Integral control.
  • Input your KP in the ‘Proportional (P)’ box and KI = 0 in the ‘Integral (I)’ box under the ‘Main’ tab. Press ‘OK’.
  • Press ‘Run’ under the ‘SIMULATION’ tab.

The Control Effort window shows the control signal u being fed to the plant, composed of the proportional (uP) and integral (uI) control signals. The Input/Output window shows the reference r and the system output y. Consider and discuss the following questions.

Problem 5: Exploring saturation and anti-windup in PI control

This problem studies the effects of actuator saturation and integrator wind-up (and anti-windup strategies). Use the same PI controller from Problem 4. To apply saturation and anti-windup:

  • Double-click the ‘PI Controller’ block to open the PI Controller window and click the ‘Output Saturation’ tab.
  • a) Click ‘Limit output’ and set the ‘Upper limit’ to be 75% of umax (from Problem 4). You typically set the lower limit to −0.75·umax, although for this problem the lower limit does not engage.
  • b) Run Simulink with PI control with saturation. Compare and discuss the control and response with those of Problem 4.
  • c) Turn on the anti-windup strategy: under ‘Anti-windup Method’, select ‘clamping’. This method stops the integration when saturation occurs and resumes when the control reduces below saturation.
  • d) Run the simulation with saturation and anti-windup. Compare and discuss the control and response with those of Problem 4 and 5(b).
