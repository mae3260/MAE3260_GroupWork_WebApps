Forced Vibrations with a Cantilever Beam

Learning Goals:

  • Activate and estimate mode shapes of a beam via sinusoidal inputs to a system
  • Understand how the input-output transfer function of a beam changes (and stays the same) as the sensor moves along the beam
  • Explain a physical meaning/experiment of frequencies of the resonant zeroes of a transfer function

Today's group work uses a cantilever beam simulation/animation. The beam is modeled after an aluminum beam clamped at the bottom (x = 0). A linear force input acts about 1/3 of the way up the beam, and horizontal position sensors along the beam create “point” measurements at specific locations (up to five sensors, A–E). For a sinusoidal force f(t) = F sin(ωt), the steady-state response is a sum over the vibrating modes, where φi(x) is the mode shape and ωni the natural frequency of mode i:

The simulator in each problem reproduces the vibrating_beam.mlx livescript in the browser. Enter up to five sensor locations as a fraction 0–1 of the beam length (toggle a sensor off to disable it) and the input frequency ω (rad/s), then click RUN. You get the Bode magnitude plot (log–log), the sensor displacement time responses, and the beam animation. The force amplitude is scaled so the largest displacement anywhere on the beam is 1 cm.
