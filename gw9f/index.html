Forced Vibrations with a Cantilever Beam

Learning Goals:

  • Activate and estimate mode shapes of a beam via sinusoidal inputs to a system
  • Understand how the input-output transfer function of a beam changes (and stays the same) as the sensor moves along the beam
  • Explain a physical meaning/experiment of frequencies of the resonant zeroes of a transfer function

Today's group work uses a cantilever beam simulation/animation. The beam is modeled after an aluminum beam clamped at the bottom (x = 0). A linear force input acts about 1/3 of the way up the beam, and horizontal position sensors along the beam create “point” measurements at specific locations (up to five sensors, A–E). Problem 3: Vary Sensor Locations along the Beam

This problem explores how the transfer function changes as the sensor location changes. In the simulator, sensors A, B, C are fixed at [1, 0.78, 0.33], and sensors D and E can be dragged along the beam.

a) Bode plots at ωn2

Simulate the system at the second resonant mode, ω = ωn2, with sensors A, B, C. Discuss with your group why the three Bode magnitude plots look as they do near ω = ωn2, and how this relates to the animation/response. Be sure to discuss physically what is occurring.

b) Move the sensor

Drag sensor D from the tip of the beam down to the clamped end. What changes in the Bode plot, and what stays the same? Why?

c) Hide mode 2

Place sensor D where the second resonant peak nearly disappears. Simulate at ω = ωn2 and compare the sensor reading with the animation. Is this location where you expected?

d) Hide mode 3

Can you place a sensor at a location that does not measure the third mode (ω = ωn3)? Find it, and discuss how you know from the animation.
