Problem 4: Observe the effect of filter time using Simulink

          

            Use the Simulink model below to explore the effects of the filter time constant, T_f. As you’ll see in the lab, the filter averages the measured angle signal for a
            short period of time before using in the control law; this has the effect of averaging out some sensor
            noise. The existence of the filter with parameter T_f adds one zero and one pole
            to the closed loop transfer function. If T_f is very small, the filter reacts
            quickly and the zero and pole can be ignored; if T_f is large, they cannot be
            ignored.
